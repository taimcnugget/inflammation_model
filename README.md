# inflammation_model


A simple systems biology model for exploring how inflammation, tissue damage, and resolution interact over time. 

## Overview
Inflammation is a dynamic process. An inflammatory response must be strong enough to respond to a stimulus (external threat, tissue damage, etc.), while regulatory mechanisms eventually supress that response and allow the system to return to homeostasis. 

This project uses a system of ordinary differential equations (ODEs) to explore that balance through three interacting variables:

* Inflammation (I) - the magnitude of the inflammatory response
* Damage (D) - tissue damage generated by ongoing inflammation 
* Resolution (R) - regulatory mechanisms that suppress inflammation
* Stimulus (S) - the initiating inflammatory signal

The goal of this project is not to reproduce a specific bilogical pathway, but to build a simplified model that can be used to explore inflammatory dynamics and ask questions about what drives resolution, persistence, and low grade inflammation.

## Model
The system is described by three coupled differential equations:

### Inflammation

Inflammation is activated by the initial stimulus and reinforced by tissue damage. It decreased through both resolution-dependent supression and natural inflammatory decay.

$$dI/dt = k_aS + k_{DI}D -k_{RI}RI-k_II$$

### Damage
Inflammation generates tissue damage, while repair mechanisms gradually remove it.

$$dD/dt = k_{ID}I-k_QD$$



### Resolution
Inflammation induces a resolution response, which subsequently deays as inflammation signals increase. 

$$dR/dt = k_{IR}I - k_RR$$

Together, these interactions create competing positive and negative feedback loops that determine whether the system resolves or remains persistently activated. 


## Biological interpretation
The model represents several broad features of inflammatoru biology. At initiating signal, such as PRR activation, inflammatory signaling pathways (NF-kB, MAPK, etc.) are induced, which promotes the production of inflammatory mediators such as TNF-a, IL-1b, and IL-6.

Sustained inflammation can contribute to cellular and tissue damagem which can then reinforce inflammatory signaling, creating a positive feedback loop. At the same time, inflammation induces regulatory mechanisms (anti-inflammatory cytokines, pro-resolution processes, etc.) that suppress the inflammaotry response and promote a return to homeostasis. 

The model therefore asks a simple systems level question:

**What determines whether an inflammatory response resolves or becomes persistent**

## Analysis
The projust explores model behavior through parameter sweeps and senesitivity analysis. Two summary metrics are used to compare simulations.
* Inflammatory AUC - total inflammatory exposure over tim
* Time to resolution - how long the system takes to fall below a defined inflammaotry threshold

Parameters controlling activation, damage-mediated fedback, and resolutoin can then be varied to determine how each process changes the overall system behavior.
